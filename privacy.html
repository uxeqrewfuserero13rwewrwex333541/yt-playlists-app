Política de privacidad — YT Playlists App

Última actualización: 24 de noviembre de 2026.

Quién la usa

YT Playlists App es una herramienta personal. La usa solo el dueño de un canal de YouTube para administrar las playlists de su propio canal.

Qué datos usa

Con la autorización del dueño, la app usa la YouTube Data API para leer la información del propio canal y sus playlists. También la usa para crear y editar esas playlists, agregarles videos y subir sus portadas. No accede a datos de otras personas.

Cómo se guardan

El permiso de acceso se guarda cifrado como secreto del repositorio privado que ejecuta la herramienta. Los datos de YouTube se usan solo para estas tareas. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

Cómo quitar el acceso

El acceso se puede revocar en cualquier momento desde la configuración de seguridad de la cuenta de Google.

Servicios de YouTube y Google

Esta app usa los servicios de la API de YouTube. Al usarla se aceptan las Condiciones del Servicio de YouTube. Además, se aplica la Política de Privacidad de Google.
